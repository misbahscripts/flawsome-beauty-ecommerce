# 💅 Flawsome Beauty – E-Commerce Website

A modern beauty product e-commerce platform built with PHP, MySQL, JavaScript, HTML & CSS.

> 💖 Built to blend style with functionality — users can browse, cart, checkout, and pay seamlessly.

## 🔥 Features
- 🛍️ Product listings with images & prices
- 🛒 Add to cart, update, and remove functionality
- 🔐 Secure user login/logout
- 💳 Razorpay Payment Gateway integration
- 📍 Google Maps API (store/checkout assist)
- 🧠 Admin panel for products, orders, and users
- 🖼️ Full responsive UI with custom CSS
- 📢 Content & social media handled in-house

## 🧠 Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP, MySQL  
- **APIs:** Razorpay, Google Maps  
- **Tools:** Git, XAMPP
